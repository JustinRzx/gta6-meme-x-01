# GTA 6 Meme Bounty Entry

![GTA 6 Meme](meme.png)

## Description

This is an entry for the make.fun GTA 6 meme bounty. The meme features the make.fun ghost mascot integrated into a parody of the classic GTA-style "MISSION PASSED" screen, highlighting the 13-year wait since GTA V was released.

## Run Instructions

1. Ensure you have Node.js 22.18 or later installed.
2. Run the following command to execute the program:

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
